# FRONTORA — Frontora 2.0

Flutter Android app for creating academic documents with an A4 preview and PDF/PNG export.

## Source package

Upload `Frontora_2.0_Flutter_Source.zip` to the repository root. The archive should contain the `Frontora_2.0_Flutter/` folder with `pubspec.yaml` and `lib/main.dart`.

## Build

After the source ZIP is uploaded, open **Actions → Android APK Build**. The workflow creates the Android platform scaffold, installs Flutter dependencies, runs analysis, and builds a release APK. The APK is available under the run's **Artifacts** section.

The initial scaffold has not yet been device-tested. Review build and analysis results before using it as a production release.
